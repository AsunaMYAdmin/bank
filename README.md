## 📋 О проекте

**Orange Bank Simulator** — это современная симуляция банковской системы, написанная на **Java 25** с использованием **Spring Boot 3.4**. Проект создан как учебно-демонстрационный, но готов к использованию в качестве бэкенда для различных приложений.


## ✨ Возможности

### ✅ Уже реализовано
| Функция | Описание | Статус |
|---------|----------|--------|
| **👥 Управление пользователями** | CRUD операции, валидация | ✅ Готово |
| **💰 Банковские счета** | Открытие/закрытие, мультивалютность | ✅ Готово |
| **💸 Транзакции** | Переводы, пополнения, снятия | ✅ Готово |
| **📊 История операций** | Детальный аудит движений | ✅ Готово |
| **⏰ Планировщик задач** | Обработка зависших транзакций | ✅ Готово |

### 🔄 В разработке
| Функция | Описание | Статус |
|---------|----------|--------|
| **🔐 JWT авторизация** | Безопасность Spring Security | 🔄 В процессе |
| **📱 Мобильная версия** | Адаптивный API | 🔄 В процессе |
| **📄 Swagger UI** | Интерактивная документация | 📅 Планируется |
| **📊 Аналитика** | Графики и отчёты | 📅 Планируется |


## 🚀 Быстрый старт

### Системные требования
- **Java 25** или выше ([скачать](https://jdk.java.net/25/))
- **Maven 3.9+** (или использовать встроенный Maven Wrapper)
- **PostgreSQL 15+** (или H2 для разработки)
