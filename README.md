## 📋 О проекте

**Orange Bank Simulator** — это современная симуляция банковской системы, написанная на **Java 25** с использованием **Spring Boot 3.4**. Проект создан как учебно-демонстрационный, но готов к использованию в качестве бэкенда для различных приложений.

## 🛠️ Технологический стек

### Backend
| Компонент | Технология | Версия |
|-----------|------------|--------|
| **Язык программирования** | Java | 25 |
| **Фреймворк** | Spring Boot | 3.4.0 |
| **Сборка** | Maven Wrapper | 3.9.6 |
| **База данных** | PostgreSQL / H2 | 15+ / 2.2+ |
| **ORM** | Spring Data JPA (Hibernate) | 6.4+ |
| **Миграции** | Liquibase | 4.27+ |
| **Логирование** | SLF4J + Logback | 2.0+ |
| **Тестирование** | JUnit 5 + Mockito | 5.10+ |
| **Документация API** | SpringDoc OpenAPI | 2.5+ |
